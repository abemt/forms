- Why: the agency audit found the notes lacked detail; from Sep 10 the house manager sends Telegram voice notes (daily/weekly/monthly) and the operator must turn them into workbooks/forms without a developer. Detail must come from her words; the app never invents events.
- Engine: faster-whisper 1.2.1 in a private embeddable Python 3.12.10 at tools/whisper/python (python312._pth enables site-packages), NVIDIA cuBLAS/cuDNN/nvrtc pip wheels (DLL dirs added in transcribe.py), model medium.en in tools/whisper/models (~1.5 GB). Installed by setup-voice.cmd -> scripts/setup-voice.ps1 (-Model, -NoGpu). PyAV decodes OGG/Opus, so no ffmpeg. tools/ is git- and docker-ignored; the Docker image has no speech engine (typed reports only). RTX 4060 laptop GPU float16: 37 s audio in ~14 s incl. model load; CPU fallback int8.
- scripts/transcribe.py: `--models-dir` (required) with `--check`, `--download <model>` or `--jobs jobs.json` (utf-8-sig; PowerShell writes a BOM). JSON-line events; GPU warm-up then CPU fallback; beam 5, VAD, initial prompt = names/programs/vocabulary (never misspellings), condition_on_previous_text=False.
- Server: services/voice/{store,transcriber,parse,apply}.ts + routes/voice.ts (/api/voice). Notes in DATA_DIR/voice/notes/<uuid>/ (note.json + audio.<ext>), settings DATA_DIR/voice/settings.json (model, device, language, vocabulary, spelling corrections). One Python process per queued batch; 'transcribing' notes are re-queued on startup.
- Parser (parse.ts): dates from spoken dates/"the Nth"/yesterday/the next day/weekdays, else file-name date (Telegram audio_YYYY-MM-DD_HH-MM-SS and audio_N@DD-MM-YYYY_..., WhatsApp PTT/AUD-YYYYMMDD) or the note's "today"; people by first name/given name/aliases (Log writer settings.aliases; defaults include Stevie/Stephen, Jay/JW/Jarrell/Gerald...) and "both/together"; shift from clock times > night > evening > day words > inherit > day. professional() rewrites to third person past tense (pronouns -> names, we -> Staff and X, DSP -> day program, 8.30 -> 8:30 AM, fillers/hedges removed). Moods go only to the sentence's subject.
- Apply (apply.ts): per (note, day, shift) one 'voice' event (source `voice:<id>`, slots from topics, inPlace replacing routine lines), plus 'program'/'home' day events; re-sending replaces, deleting removes; transcript block stored in draft.sourceNotes; new drafts get range [min,max] of mentioned days, existing drafts only widen; voice drafts default routineLevel 'essentials'.
